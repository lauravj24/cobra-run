# cobra-run
Juego de laberinto 2D donde controlas una cobra que debe escapar de cada nivel antes de que el tiempo se agote, enfrenta enemigos que recorren los pasillos, recoge power-ups para obtener superpoderes y transformarte visualmente, recupera vidas atrapando presas en el laberinto, y acumula puntaje sobreviviendo y eliminando enemigos.
